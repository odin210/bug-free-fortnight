# ⛳ 골프 간편 스코어 & 통계 트래커 (Golf Tracker)

국내 골프장 코스 정보와 연동하여 라운드 도중 3초 만에 오버파 스코어, 티샷 방향, 퍼팅 수를 기록하고 통계를 분석해 주는 모바일 웹 앱입니다.

---

## ✨ 주요 특징
1. **👤 닉네임 기반 초간편 멀티 유저 지원**:
   - 복잡한 회원가입이나 로그인 절차 없이, **닉네임(이름)**만 입력하거나 선택하면 각 사용자별로 스코어 기록과 통계가 안전하게 분리되어 보관됩니다.
2. **0.5초 필드 원터치 입력 (오버파 기준)**:
   - `0 (파)`, `+1 (보기)`, `+2 (더블)`, `-1 (버디)` 대형 스코어 버튼
   - `[ ⬅️ 좌측 ]  [ 🎯 페어웨이 ]  [ ➡️ 우측 ]` 3버튼 티샷 (파4/5 전용)
   - 파3 홀 티샷 자동 생략 & GIR(온그린) 자동 판별
3. **국내 주요 골프장 정밀 프리셋 & 현장 Par 즉시 수정**:
   - 대영힐스 CC (력/청/미), 로드힐스 CC (로드/힐스/레이크), 올림픽 CC, 써닝포인트 CC, 마론뉴데이 CC, 자유로 CC 등
   - 라운드 도중 `[P3] [P4] [P5] [P6]` 버튼으로 1초 만에 기준 파 변경 가능
4. **시원한 스코어카드 & 탭하여 즉시 수정**:
   - FW티샷 행과 GIR적중 행이 분리되어 시인성 극대화
   - 종료된 라운드도 스코어카드의 홀/스코어 셀을 탭하면 즉시 수정 모드로 연결
5. **카카오톡 결과 복사 공유 & 데이터 JSON 백업/복원**

## 🌐 무료 웹 배포 방법 (스마트폰에서 바로 사용하기)

본 앱은 **단일 `index.html` 파일**로 완결되어 있어 어떤 무료 정적 호스팅이든 1분 만에 배포할 수 있습니다:

### 방법 1. Vercel (가장 빠르고 간편 - 1분 완료)
1. [vercel.com](https://vercel.com)에 무료 가입합니다.
2. 이 `golf-score-tracker` 폴더를 Vercel 대시보드에 드래그 앤 드롭하거나 GitHub 저장소와 연동합니다.
3. 생성된 URL (예: `https://your-golf-tracker.vercel.app`)을 스마트폰 브라우저(사파리/크롬)로 엽니다.
4. **스마트폰 '홈 화면에 추가'**를 누르면 앱스토어 앱처럼 전체화면으로 사용 가능합니다.

### 방법 2. GitHub Pages
1. GitHub에 새 저장소(`golf-score-tracker`)를 생성하고 `index.html`을 업로드합니다.
2. 저장소의 `Settings` ➔ `Pages` ➔ Branch를 `main`으로 설정하고 `Save`를 누르면 무료 웹사이트 주소가 발급됩니다.

### 방법 3. Netlify
1. [netlify.com](https://app.netlify.com/drop)에 접속합니다.
2. 이 폴더 전체를 브라우저 창에 드래그 앤 드롭하면 즉시 배포 URL이 생성됩니다.
